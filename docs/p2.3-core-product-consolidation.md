# P2.3 — Core Product Consolidation

## Product decision

Veyra is a platform for verifiable paid workflows for people and
AI agents. The external seller marketplace remains a frozen infrastructure
capability and is not part of the primary catalog, Home, Runner, Machine
discovery, or main Console navigation.

## Delivered scope

### GitHub Project Due Diligence

- deterministic final verdict with confidence and evidence coverage;
- explicit conditions and blocking findings;
- stable fallback behavior when upstream GitHub evidence is partial;
- JSON and Markdown export;
- shareable report URL and Arc proof trail.

Multi-repository comparison is deliberately deferred.

### Veyra Agent API

- dependency-free typed TypeScript SDK;
- normalized `AgentCommerceApiError`;
- idempotent quote and run helpers;
- terminal-state polling with bounded transient retries;
- structured JSON and Markdown report retrieval;
- production-ready GitHub Due Diligence agent example;
- credential onboarding and end-to-end quickstart;
- curated workflow-only discovery.

### Curated catalog

The core catalog contains:

- GitHub Project Due Diligence;
- Market Context Brief;
- Sentiment & Tone Report;
- Builder Update Summary.

Custom tasks and external seller workflows are not shown in the primary
catalog.

### Production observability

- workflow failures and stale execution detection;
- paid provider call latency and failures;
- checkout credit/refund and unresolved-payment detection;
- Arc proof failure and delay detection;
- daily Vercel monitor on the current plan, with support for a faster external scheduler;
- structured log alerts plus optional webhook delivery;
- explicit retry and reconciliation policy.

### Product cleanup

- marketplace removed from core positioning;
- seller internals removed from primary Console navigation;
- legacy review/demo/launch surfaces redirect to the current product;
- public Phase and Canary language removed;
- README and About aligned to verifiable paid workflows.

## Acceptance

P2.3 is complete when:

- GitHub reports expose the new verdict and both exports;
- SDK build and SDK flow tests pass;
- Machine discovery returns only curated workflows;
- the Operations dashboard loads aggregate production metrics;
- the scheduled monitor is authorized by `CRON_SECRET`;
- Home and Runner do not query or render seller workflows;
- lint, focused tests, typecheck, and production build pass;
- the deployed Production smoke returns a GitHub report with verdict and Arc
  verification metadata.
